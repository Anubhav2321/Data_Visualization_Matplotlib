## 📚 Matplotlib Concepts

Some important Matplotlib concepts covered in this project include:

### Figure

The complete canvas or window containing one or more plots.

### Axes

The area where the actual data visualization is drawn.

### Axis

The horizontal and vertical reference lines used to represent data.

### Function

Predefined Matplotlib operations used to create and customize visualizations.

### Method

Operations performed on Matplotlib objects such as `Figure` and `Axes`.

### Arguments

Values provided to functions or methods.

### Keyword Arguments

Named arguments used to customize plots, such as color, marker, linewidth, and labels.

### Object-Oriented API

A more structured approach to Matplotlib where visualizations are created and controlled using Figure and Axes objects.

### DPI

**Dots Per Inch**, which controls the resolution of a saved visualization.

## 📊 Types of Visualizations

### Line Plot

Used to display trends and changes in data.

### Bar Chart

Used to compare values between different categories.

### Pie Chart

Used to represent parts of a whole.

### Scatter Plot

Used to visualize relationships between two numerical variables.

### Histogram

Used to understand the distribution and frequency of numerical data.

## 🧪 Example

A simple Matplotlib visualization can be created using Python:

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 20, 15, 30]

plt.plot(x, y)

plt.title("My First Visualization")
plt.xlabel("X Axis")
plt.ylabel("Y Axis")

plt.show()
```

This creates a basic **line plot** from the given data.
